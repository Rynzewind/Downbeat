# Downbeat third-party notices

Downbeat test builds include Flutter and their transitive notices, yt-dlp (The Unlicense), and FFmpeg. The Windows test bundle uses the pinned GPL FFmpeg build identified in `tools/runtime/windows-runtime.json`. The Android build includes `yt-dlp-android` 2.0.2 (MIT) and `ffmpeg-kit-full` 8.1.7 (LGPL build). Source and license details are available from the respective upstream projects.
